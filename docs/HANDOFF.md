# Передача работы: Windows → MacBook (18.11.2026)

Работа продолжается на MacBook с симулятором. Этот файл — точка входа для новой сессии Claude Code на маке.
Правила, роли агентов, хуки, чек-лист и журнал дефектов лежат в репозитории и подхватываются автоматически
(`CLAUDE.md`, `.claude/`, `docs/`).

## Подготовка мака (один раз)
```bash
brew install swiftlint node gh
git clone https://github.com/Sokonlnl/sber-health-app.git && cd sber-health-app
chmod +x scripts/local-verify.sh
scripts/local-verify.sh
```
Node нужен хукам Claude Code (`.claude/hooks/*.mjs`). Затем `claude` в папке репозитория.

## Новый цикл дизайн-ревью (вместо CI)
1. swiftui-builder правит код → хук проверяет токены → design-system-keeper (must-fix → обратно builder).
2. `scripts/local-verify.sh` — сборка, SwiftLint, скриншоты `build/local/<время>/{home,pressure,pressureSheet,loading,empty,error}.png`.
   Ошибки компиляции видны сразу; красная локальная сборка — не пушить.
3. design-reviewer сравнивает скриншоты с `docs/design/home-figma-63-25250.png` (перед этим по C15 снять Figma 63:25250 заново)
   и с разделом «Экран 1/2» `docs/DESIGN.md`.
4. Человек смотрит то же в симуляторе (приложение остаётся открытым на главном).
5. Коммит через ворота (`Verified-by: keeper, local-verify <время>`), пуш; CI — финальная проверка (UI-тесты, аудит, видео).
