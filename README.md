# HealthMonitor

Интерактивный iOS-прототип мониторинга здоровья. На главной есть карточки показателей и вывод о самочувствии. На экране давления можно посмотреть последнее измерение, переключить период графика и сравнить значения. Данные демонстрационные.

## Запуск

Нужен Mac с Xcode 15.3 или новее и установленным симулятором iPhone с iOS 17 или новее.

1. Клонируйте репозиторий и откройте [HealthMonitor.xcodeproj](HealthMonitor.xcodeproj).
2. Выберите схему **HealthMonitor** и симулятор iPhone.
3. Нажмите **Run** (⌘R). При первом открытии Xcode загрузит зависимости Swift Package Manager.

## Проверки

- **Product → Test** (⌘U) запускает unit- и UI-тесты общей схемы. Пока в репозитории нет утверждённых PNG-эталонов, snapshot-тесты записывают снимки и сообщают о падении.
- `scripts/local-verify.sh` собирает проект и снимает кадры на симуляторе. Для скрипта нужен SwiftLint (`brew install swiftlint`).
- GitHub Actions использует тот же проект и сохраняет скриншоты и видео в артефактах прогона.
